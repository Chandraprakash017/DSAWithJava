# DSAWithJava

## Overview

`DSAWithJava` is a Java practice repository for data structures and algorithms. It contains concise, beginner-friendly solutions across arrays, recursion, search, and tree traversal problems.

## Repository Structure

- `Arrays/` - Array-based algorithms, binary search, two-sum, duplicates, missing number, and recursion problems.
- `Trees/` - Tree traversal and binary tree-related practice.
- Root folder - Standalone Java examples and string/array practice tasks.

## Highlights

- Simple Java implementations with clear problem focus
- Covers common DSA patterns useful for interview preparation
- Organized by topic for easy navigation and practice

## How to Run

1. Open a terminal and change to the repository root:

   ```bash
   cd /Users/rajathakur/Desktop/java-practice
   ```

2. Navigate to the folder containing the file you want to run:

   ```bash
   cd Arrays
   ```

3. Compile the Java file:

   ```bash
   javac TwoSum.java
   ```

4. Run the compiled class:

   ```bash
   java TwoSum
   ```

If the file is in the root folder, compile and run it from the repository root instead.

## Contributing

- Add new practice problems in the appropriate folder.
- Keep solutions focused and easy to understand.
- Use descriptive class names and comments where helpful.

## Notes

- This repository is intended for learning and interview preparation.
- No external dependencies are required; it uses plain Java.
